从圣索菲亚案例的同类问题继续检查：声明了要求、执行了流程，仍可能遗漏实际验收条件。基线为 `2a682b1`。本轮覆盖原始目标绑定、判断校准、数值仪器、优化盲区、外部结算及其组合路径；修复不增加新的角色或普通任务的提交字段。

## 已复现并修复

在隔离项目中调用真实 init、stamp、bind、close、audit/Gate 和 completion receipt。判词中的“controlled seat fixture”是协议测试输入，不冒充独立模型观察。

| 路径 | 基线的问题 | 本轮行为 |
| --- | --- | --- |
| 原始目标 | 非视觉 Objective 在批准后改写，仍能交付 | 所有任务冻结 Objective/Request/Goal 与已捕获原请求 |
| 校准锚点 | 不同文件名、相同内容可充当好坏样本；批准后可换内容再重判 | 全部校准项冻结不同的样本字节，拒绝换尺 |
| 校准判词 | 样本哈希错误仍可通过；同状态矛盾判词由最后一条覆盖 | 好坏判词都须精确路径和完整 SHA-256，派生 id 也检查矛盾 |
| 优化盲区 | 已声明校准盲区，却用 UNVERIFIABLE 配额免除 | 无显式冻结 waiver 时，至少一个校准盲区实际 PASS |
| 人工判断 + 外部要求 | judged AC 的 external 完全未执行 | 独立执行外部要求；内容 PASS 不代表外部批准 |
| 外部仪器和缓存 | 外部检查脚本未冻结；上一版产物的 PASS 可缓存给新版 | 冻结直接声明的外部脚本；缓存绑定实际项目、产物、契约和冻结仪器 |
| 带引号的脚本 | 含空格的脚本路径会被空格切分漏掉，换脚本仍可通过 | 共享 shell 参数解析，NUL 分隔路径；不合法引号在账本变更前拒绝 |
| 数值读取 | `.5` 变成 `5`，`1e3` 或 `1junk` 变成 `1` | 校验完整十进制捕获；规范化小数，明确拒绝不支持的表示 |
| 噪声容差 | 负标准差/方差取绝对值后，能掩盖真实退步 | 负离散度为 BROKEN；内部科学记数形式的 spread 不再截断 |

规范比较共 17 个案例：15 个错误条件在基线获得完成回执，修复后全部拒绝；正常校准案例在两版均 GO；重复 AC id 这个已有保护在两版均拒绝，没有算成新修复。实际命令、原回执、监督执行记录和源文件都保留在原始归档中。

同一产物仍能在窗口内复用查询。不同项目、不同产物、不同冻结仪器不能借用旧批准；无绑定的历史缓存或未来时间戳会重新查询，零窗口不缓存。macOS `/var` 与 `/private/var` 别名使用物理路径统一，避免同一项目重复查询。

## 非视觉独立前向验证

按 skill-creator 运行了两次独立只读复审，未提供预期判词或本次补丁诊断。

第一份 CSV 报告遗漏 AMER 净收入 160，总计写成 180，两条“文件非空/存在总计文字”检查仍为 PASS。冷席独立计算正确总计 340，指出内容和 AC 覆盖缺口。它证明文件自检不等于内容正确；没有声称这两条弱 AC 已被通用语义程序自动修好。

另一冷席读取本轮修改后的 skill、原始请求、CSV、完整报告和好坏样本，实际给出内容 PASS、好样本 PASS、遗漏地区的近似坏样本 FAIL；同时观察到当前报告的受控外部回执为 PENDING，没有宣称 GO。

控制器原样保存该报告并绑定其实际内容判词和校准哈希。原接受入口在 PENDING 时返回 NO-GO，且不增加 false-complete；仅将受控外部源切换为 APPROVED 后，原 receipt 才得到 `completion_verified=true`。报告字节、冷席报告、契约、迭代和原预算不重置。实际监督的外部查询顺序是 `75,75,75,0`；前三次是零窗口下的验证/终验查询，最后一次读取批准后的源。

这是预先准备的文件产物、受控审批源和原生独立产物复审的组合测试。它不是实际审批服务、完整 cc-haha 生命周期、任务建设速度或普遍成功率的证据。

## 兼容边界

这次将原文/校准内容绑定扩展到非视觉契约。已经盖戳但没有这些绑定的旧契约需要正常修订、批准和重新复审；不能改写托管 freeze 来追认历史观察。文件名式旧校准判词也需要真实重判及内容绑定，不自动补造哈希。普通确定性任务继续使用原提交入口，不额外强制冷席或新表单。

原始目标的语义覆盖仍需要 agent 做需求复核。新增路由在作者选择 AC 标签前，按原始请求判断内容判读或树外结算需求；不是靠增加关键词声称任意任务都能自动得到完整 AC。直接命名的脚本被冻结，npm 解析、传递依赖和外部服务的真实性仍需要可信仪器和适当声明。无新反例不等于证明仓库没有其他缺陷，也没有新的综合自评分。
